MoneyPulse Privacy Notice

MoneyPulse is a private personal-finance PWA. Financial records remain in the owner's restricted Google Sheet. GitHub Pages hosts only public application files.

Google sign-in

MoneyPulse uses Google Sign in to verify the authorized account. Identity tokens are sent to the owner's Apps Script API for verification and are not written to the workbook or audit log.

Local storage

The connection-proof build stores only a random device identifier and application shell files. Future offline financial storage will be documented before it is enabled.

Sharing

MoneyPulse does not sell or intentionally share personal financial information with third parties.
